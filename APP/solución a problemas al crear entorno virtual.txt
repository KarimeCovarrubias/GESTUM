# SOLUCIÓN
    Corre este comando una sola vez en esa misma terminal de PowerShell:
        Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

    Te va a preguntar algo como ¿Desea cambiar la directiva de ejecución? — escribe S (sí) y Enter.
    Esto permite correr scripts locales (como el de activar tu venv) sin comprometer la seguridad de tu sistema, ya que solo afecta tu usuario, no la máquina completa.

    Después de eso, vuelve a intentar:
        powershell
        venv\Scripts\activate

EN UBUNTU
Instala las herramientas oficiales que Ubuntu requiere para compilar Python desde cero:
    sudo apt update && sudo apt install build-essential libssl-dev zlib1g-dev \
l   ibbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \
    libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev -y

Descargar el código fuente oficial de Python 3.12:
    wget https://www.python.org/ftp/python/3.12.3/Python-3.12.3.tgz

Descomprime el archivo:
    tar -xf Python-3.12.3.tgz
Verificacion: Si ejecutas el comando ls, ahora verás la carpeta Python-3.12.3 
listada en color azul (o destacada como directorio).

Accede al directorio recién creado:
    cd Python-3.12.3

Configura la instalación usando altinstall para no sobrescribir el Python por defecto de tu sistema Ubuntu:
    ./configure --enable-optimizations
    make -j$(nproc)
    sudo make altinstall

Verificacion: Al finalizar, ejecuta python3.12 --version y te devolverá Python 3.12.3.
